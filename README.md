# Painel Financeiro

Painel para controle financeiro com limite global, boletos e saldos disponíveis.

## Funcionalidades

- ✅ Controle de limite global
- ✅ Saldo disponível (combustível e pedágio)
- ✅ Cadastro de boletos com data de vencimento
- ✅ Controle de pagamentos (parcial, total, adiado)
- ✅ Resumo mensal
- ✅ Alertas de diferença no limite
- ✅ Exportação de dados
- ✅ Filtros por período

## Como usar

1. Acesse o painel
2. Cadastre os boletos com suas datas de vencimento
3. Atualize os saldos disponíveis
4. Acompanhe os resumos e alertas
5. Exporte os dados quando necessário

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage para persistência
